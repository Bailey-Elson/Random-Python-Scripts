# Random-Python-Scripts
Random little python scripts that have helped me over the years. Normally to do with automation of tasks or spreadsheet parsing.

All scripts have pip install commands for any libaries that are required at the top of the scripts



combine-csv.py
Combines multiple csv in folder into one csv file 

combine-to-sheet.py
Combines multiple csv files into excel document, each csv on a seperate sheet in file

compare-arrays.py
Compares arrays and prints values that are only in the first array

copy-and-paste-machine.py
Prints string value with keyword replaced from list of replacement words in array. Usefull for when needing the same text over and over with small difference

excel-to-sql.py
Converts data from excel sheet to sql commands, useful for import data from excel sheets

files-in-folder.py
Lists all files in folder, used to make this file here.

multiline-to-array.py
converts multiline string to array. Array is easier to loop through

multiline-to-sql.py
converts multiline strings to sql commands

multiline-to-unique-array.py
converts multiline string to array with only unique values. Array is easier to loop through

multiline-unique-arrays-with-differences.py
converts multiline strings to unique arrays and compares array to tell the differences.

new-line-after-comma.py
takes string and adds new line after each comma, helpful for formatting sql commands that default to one line

unique-col-values.py
takes excel document and prints unique values in each column

wifi-QR-test.py
Makes a QR code for people to scan to automatically join wifi networks. Saves the QR Code as an image.
